Relier un bot à l’API

L’adresse doit être celle du bot avec l’API de diagnostic installée. Les clés restent sur cet ordinateur.

Nouvelle connexion

Adresse HTTPS du service du bot, avec son éventuel préfixe. Ne pas ajouter /api/dashboard. Utilisez la clé DASHBOARD_API_TOKEN du bot, jamais son token Discord.

Verrouillez les champs pour éviter une modification accidentelle. Les clés sont dans data/local-dashboard/.env, ignoré par Git.
