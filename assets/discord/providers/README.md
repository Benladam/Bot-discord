# Logos des plateformes musicales

Favicons publics des domaines listés dans `sources.json`, récupérés au format
PNG via le service Google S2 (29 septembre 2026). Ils servent uniquement à
identifier la plateforme d'origine d'une musique, sans suggérer de partenariat.
Les marques et logos restent la propriété de leurs titulaires respectifs ; la
licence MIT du code ne confère pas de droits sur ces marques.

Les fichiers sont livrés avec le bot et joints aux messages Discord : aucun
service d'images externe ni site web du bot n'est nécessaire à l'exécution.
Pour rafraîchir les ressources, exécuter `tools/refresh-provider-icons.ps1`
depuis PowerShell, puis vérifier visuellement les images avant publication.
